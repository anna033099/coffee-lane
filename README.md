# ☕ 咖啡巷物語 Coffee Lane

在巷口經營一間精緻的小咖啡館：烘豆、沖煮、做點心與輕食、招待客人、裝潢擴店、結交常客、拜訪鄰居。
玩法參考《LINE I Love Coffee》與《Hello Seafood 2》這類經營遊戲。純瀏覽器網頁遊戲，放在 GitHub Pages 就能玩。

> 本作為原創作品：遊戲名稱、角色、劇情、美術（程式繪製）與程式碼皆為原創，未使用任何其他遊戲的素材或文字。

### 自動經營（逐步解鎖）

自動功能要升級到指定等級、付一次聘請費才能使用：店內事件（Lv3）→ 烘豆（Lv5）→ 領任務獎勵（Lv6）→ 離線營業（Lv9，未解鎖時離線只結算 1 小時）→ 員工打氣（Lv8）→ 沖煮（Lv10）→ 點心（Lv12）→ 鄰居互動（Lv14）→ 餵店貓（Lv15）→ 料理（Lv17）→ 外送（Lv20）→ 招攬路人（Lv22）→ 常客訂單（Lv26）。聘請後可以個別開關，並可設定保留金額。

## 操作

- 手機請**橫著玩**。
- 點機器操作、點客人／店員／貓互動；在店員身上往上滑可以加油。
- 雙指或滑鼠滾輪縮放，拖曳移動畫面。
- 進度自動存在瀏覽器（localStorage）。換裝置時在「設定」匯出存檔碼，到新裝置貼上。

## 換成 AI 繪製的人物

人物預設是程式畫的 Q 版角色，可以用 AI 繪圖工具生成後放進 `assets/chars/` 替換，不用改程式。
完整的 AI 指令範本、圖片規格與角色代號表見 **[ART_GUIDE.md](ART_GUIDE.md)**；排版工具在 `tools/sheet.html`。

## 發布到 GitHub Pages

1. 打開 repo 的 **Settings → Pages**。
2. **Source** 選 *Deploy from a branch*，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
3. 一兩分鐘後網址是 `https://anna033099.github.io/coffee-lane/`。

## 本機執行

ES Modules 不能直接雙擊開啟，需要本機伺服器：

```bash
python3 -m http.server 8000
# 打開 http://localhost:8000
```

## 專案結構

```
index.html             進入頁
css/style.css          介面樣式（皮革縫線風）
lib/                   Three.js r169（離線內附）
js/main.js             啟動、主迴圈、自動存檔、離線結算
js/data.js             所有數值：豆子、配方、點心、輕食、家具、擴店、員工、常客、鄰居
js/state.js            存檔結構、讀寫、匯出匯入
js/sim.js              遊戲邏輯（與畫面無關，離線也能跑）
js/auto.js             自動經營引擎
js/quests.js           劇情、循環與每日任務
js/chara.js            Q 版角色繪製與 PNG 覆蓋
js/cat.js              店貓
js/icons.js            圖示
js/audio.js            合成音效與背景爵士樂
js/scene.js            3D 場景同步、角色、對話泡泡、觸控
js/ui/                 介面各面板
js3d/                  3D 引擎、模型、程式材質、縮圖
js3d/dishes.js         所有菜色的 3D 擺盤與食譜照片
assets/chars/          （選用）AI 角色圖與 manifest.json
tools/sheet.html       角色圖排版工具
```

調整平衡（價格、時間、經驗值）只需要改 `js/data.js`。
