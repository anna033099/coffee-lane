# ☕ 咖啡巷物語 Coffee Lane

在巷口經營一間自己的小咖啡館：烘豆、沖煮、上架、招待客人、裝潢擴店、結交常客。
純瀏覽器網頁遊戲，不需要安裝，放在 GitHub Pages 就能玩。

> 本作為原創作品：遊戲名稱、角色、美術（全部由程式繪製的 SVG）與程式碼皆為原創，未使用任何其他遊戲的素材。

## 怎麼玩

1. **烘豆**：點吧台上的紅色烘豆機，選生豆開始烘焙。烘好要記得收成，放太久會烤焦。
2. **沖煮**：點銀色咖啡機，用熟豆（和牛奶、焦糖等食材）煮出一批飲品，收成後放上展示櫃。
3. **營業**：客人會自己進門找座位點餐，店員從展示櫃拿飲品送過去，客人喝完付錢。
4. **員工**：店員送餐會消耗體力，點店員可以幫他加油；升級後可以雇用更多人。
5. **裝潢**：買桌椅、擺飾、壁飾、地板與牆面，提高人氣 ♥。人氣越高，客人越多、小費越多。椅子要擺在桌子旁邊客人才會坐。
6. **街頭招攬**：用名片跟路人聊天，聽懂他的需求並推銷對的東西，他就會變成常客。常客會多給小費，好感升級還會送禮。
7. **擴店**：升級後擴建店面，地方更大、吧台能放更多機器。

左上角的任務會一步一步帶新手上手。

### 操作

- 手機請**橫著玩**；右上角按鈕可切換全螢幕。
- 店面可用右下角 ＋／− 、滑鼠滾輪或雙指縮放，放大後可拖曳移動畫面。

### 存檔

進度自動存在這台裝置的瀏覽器（localStorage）。要換裝置時，在「設定」裡匯出存檔碼，到新裝置貼上讀取。清除瀏覽器資料會讓存檔消失。

## 發布到 GitHub Pages

1. 打開這個 repo 的 **Settings → Pages**。
2. **Source** 選 *Deploy from a branch*，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
3. 等一兩分鐘，遊戲網址會是：`https://<帳號>.github.io/coffee-lane/`

## 在自己電腦上執行

遊戲使用 ES Modules，直接雙擊 `index.html` 會被瀏覽器擋下，需要開一個本機伺服器：

```bash
python3 -m http.server 8000
# 再打開 http://localhost:8000
```

## 專案結構

```
index.html            進入頁
manifest.webmanifest  加到主畫面用的設定（之後包成 App 也會用到）
css/style.css         介面樣式
icons/                App 圖示
js/main.js            進入點：主迴圈、自動存檔、畫面縮放
js/data.js            遊戲數值：豆子、食材、配方、家具、擴店、員工、常客
js/state.js           存檔結構、讀寫、匯出匯入
js/sim.js             遊戲邏輯：機器、客人、店員尋路、擺設規則、常客
js/quests.js          新手任務與每日循環任務
js/art.js             所有 SVG 美術（等角家具、牆面、地板、角色、圖示）
js/room.js            店面場景繪製、深度排序、縮放拖曳、點擊判定
js/ui.js              介面：資訊列、面板、裝潢模式、街頭招攬
js/audio.js           合成音效（不需要音檔）
```

想調整遊戲平衡（價格、時間、經驗值）只需要改 `js/data.js`。
